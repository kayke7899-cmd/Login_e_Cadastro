# DevSchool - Plataforma de Ensino de Programação

Bem-vindo ao repositório do **DevSchool**, um projeto front-end desenvolvido para simular a interface de cadastro e login de uma plataforma educacional focada na área de tecnologia.

O objetivo deste projeto é praticar a estruturação semântica de HTML5 e a estilização responsiva e moderna com CSS3, criando uma experiência de usuário limpa e intuitiva.

##  Funcionalidades

- **Página de Cadastro (`cadastro.html`)**:
  - Layout dividido em duas colunas: apresentação da marca/benefícios e formulário de inscrição.
  - Campos para: Nome completo, E-mail, Telefone, Data de nascimento, Senha e Confirmação de senha.
  - Destaque visual para os benefícios da plataforma (Cursos, Atividades, Relatórios, Certificado).

- **Página de Login (`login.html`)**:
  - Interface centralizada e minimalista para acesso dos alunos.
  - Campos para E-mail e Senha.
  - Link direto para a página de cadastro para novos usuários.

##  Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização completa, incluindo:
- **Visual Studio Code**: Editor de código 
  - Flexbox para layout da página de cadastro.
  - Design responsivo básico.
  - Paleta de cores personalizada (tons de verde e branco).
  - Efeitos de hover e foco em inputs e botões.
